📌 Project Overview

CrackDaddy demonstrates how rainbow table attacks and wordlist-based attacks work against hashed passwords.

It includes:
- Ready-to-use small rainbow tables
- Python scripts to generate custom rainbow tables
- External large rainbow tables and rockyou.txt wordlist (MEGA)

🧾 Language Used
* Python 🐍

🔑 Supported Hash Algorithms
* MD5
* NTLM
* SHA1
* SHA224
* SHA256
* SHA3-256

📦 Large Table Details
* 1,400,000 hash–password pairs per algorithm
